# おかねの流れ帳

話すだけで「どこから → どこへ・いくら」を記録して、置き場所ごとの残高を合わせておくスマートフォン向けの家計簿Webアプリです。
ゆうちょ・セブン銀行・PayPay・封筒・財布（〈昼代〉と〈自由〉に分けて管理）の間のお金の動きを記録します。

アプリを開く：https://sh0zy.github.io/okane-nagare/

- 会員登録・ログイン・支払いは不要です。記録は利用者のブラウザの中（端末ごと）に保存し、サーバーには送信しません。
- 話した言葉の読み取り（どこから・どこへ・いくら）は、端末の中の決まった規則と辞書で行います（AI は使っていません）。
- 声を文字にする部分はブラウザの音声認識を使います。多くのブラウザでは通信が必要で、音声の扱いはブラウザによります。音声そのものはアプリに保存しません。
- スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使え、一度開いた後はオフラインでも起動できます（声の入力は通信が必要なことがあります）。

このリポジトリには、公開用のビルド済みファイルだけを置いています。
